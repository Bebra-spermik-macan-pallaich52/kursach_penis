# Первая часть курсового проекта — семь отдельных проектов FastAPI

В каждой папке находится полный самостоятельный проект соответствующего этапа. Можно скопировать только одну папку в любое место и работать в ней: у неё свои исходники, зависимости, миграция, настройки, хранилище и README. Общего приложения, общей библиотеки и общих файлов запуска в корне нет.

| Проект | Срок | Содержимое |
|---|---|---|
| [01_orm_migrations](01_orm_migrations/README.md) | 02.11.2026 | ORM, SQL-миграция, учебные данные, проверка БД |
| [02_fastapi_routes](02_fastapi_routes/README.md) | 09.11.2026 | Свои модели и БД, маршруты FastAPI |
| [03_pydantic_schemas](03_pydantic_schemas/README.md) | 16.11.2026 | Свои модели и маршруты, схемы Pydantic |
| [04_auth_roles](04_auth_roles/README.md) | 23.11.2026 | Свой API с JWT, ролями и правами |
| [05_word_excel_reports](05_word_excel_reports/README.md) | 30.11.2026 | Свой API с ролями и отчётами Word/Excel |
| [06_api_testing](06_api_testing/README.md) | 07.12.2026 | Свой API, автотесты, тестовая документация |
| [07_final_api](07_final_api/README.md) | 14.12.2026 | Итоговый самостоятельный API и документы для сдачи |

Каждый следующий проект включает собственную копию уже реализованных функций. Импортов из соседних папок, общих зависимостей requirements и общей .env нет. Python-код написан без комментариев и docstring. Docker и Django не используются.

Выберите папку, откройте её отдельно в редакторе и выполните её README. Первые три проекта предназначены для локального учебного запуска без авторизации; JWT и ограничения ролей появляются в четвёртом. Для сдачи завершённого первого этапа используйте 07_final_api. Срок персонального ТЗ — 15.12.2026.

На фотографии для последних двух дат указан 2025 год. Здесь принят 2026 по остальному плану и персональному ТЗ; опечатку нужно уточнить у преподавателя.

Результаты проверки каждого проекта находятся внутри него в CHECKS.md; тестовая документация — в собственных docs/testing проектов 6 и 7. Формальные вопросы записки перечислены в 07_final_api/docs/coursework/ПЕРЕД_СДАЧЕЙ.md.

Самостоятельность проверена для каждой папки: отдельная копия вне репозитория, новое окружение и пустая БД. Все 324 проверки БД/HTTP повторно успешны; полный набор итогового проекта в отдельной копии — 88 успешных тестов.
