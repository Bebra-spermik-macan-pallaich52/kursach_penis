Запись успешного прогона не доказывает применение TDD ко всей истории разработки; полная история исходных red/green-циклов не восстанавливалась.

Нагрузочные, длительные и отказоустойчивые испытания не проводились. Два обычных запуска не доказывают стабильность при больших нагрузках. Windows и PostgreSQL 18 не запускались. Проверка полей отчётов библиотеками не заменяет визуальную приёмку в Microsoft Office. Django исключён из объёма первого этапа.
