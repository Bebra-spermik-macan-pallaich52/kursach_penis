# Семь этапов разработки FastAPI

Каждая папка содержит самостоятельную версию. Копировать код из предыдущего этапа или запускать корневой проект не нужно. У каждой версии собственные базы и `.env`; все используют PostgreSQL без Docker и Python 3.12.

Этапы накопительные: маршруты появляются во втором, схемы — в третьем, ограничения прав — в четвёртом, отчёты — в пятом, полный набор автотестов и тестовая документация — в шестом, документы итоговой сдачи — в седьмом. Первые три этапа являются учебными локальными версиями без авторизации; итоговым требованиям по безопасности соответствует версия с этапа 4.

На фото для двух последних этапов стоит 07.12.25 и 14.12.25. Здесь принят 2026 год по первым пяти датам и персональному ТЗ: REST API сдаётся до 15.12.2026. Даты фотографии сохранены в этом пояснении; расхождение необходимо уточнить у преподавателя.

Код приложения написан без комментариев и docstring. Названия, README и отдельные документы объясняют его назначение. Локальные библиотеки Swagger/ReDoc сохранены с лицензиями авторов. Скриптов генерации пояснительной записки, презентаций и диаграмм нет.

Корневая версия и ветка simple-student сохранены. Django не изменён. Сводка фактических проверок — в [VERIFICATION.md](VERIFICATION.md).
