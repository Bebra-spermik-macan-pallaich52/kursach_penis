# Тест-кейсы первого этапа

Основание и объём: [TEST_PLAN.md](TEST_PLAN.md). Сценарии ниже группируют
параметризованные автоматические проверки; один сценарий не равен одному тесту.
Предусловия, если не указано иное: отдельная PostgreSQL-транзакция, фикстуры
`accounts`, `headers`, `olympiad`; сегодня — текущая дата ОС. Каталог файлов временный.
Фактический результат каждого сценария: пройден в итоговом прогоне 22.10.2026.

## TC01 — Хеши, вход и JWT

Требования: R04 R16.

Действия: Проверить разные соли; верный/неверный пароль; повреждённый, просроченный токен и отсутствующий аккаунт.

Ожидается: Верный вход 200; неверный 401; исходный пароль не восстанавливается.

Автоматизация: `test_password_hashes`, `test_login_profile`, `test_bad_login`, `test_inactive_login`, `test_invalid_token`, `test_missing_user_and_expired_token`.

Факт: соответствует ожидаемому, успешно.
