# Диаграммы

ERD сверена с моделями и реальной схемой PostgreSQL. `*.dot` — редактируемые
исходники Graphviz, SVG — векторные копии, PNG вставлены в DOCX.
Пример пересборки: `dot -Tpng -Gdpi=160 erd.dot -o erd.png`.
`use_cases.svg` — редактируемая схема вариантов использования с актёрами;
её PNG получен браузерным отображением SVG.

Архитектура и алгоритмы отражают первый этап. Неизменяемый published и отсутствие
автоматических порогов призовых мест соответствуют принятым решениям из REQUIREMENTS.
