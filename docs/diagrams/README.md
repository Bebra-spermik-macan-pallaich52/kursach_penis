# Схемы проекта

- [Архитектура](architecture.svg) — модули сервера, клиент и база данных.
- [База данных](erd.svg) — таблицы, ключи и связи.
- [Варианты использования](use_cases.svg) — действия четырёх категорий пользователей.
- [Запись на олимпиаду](enrollment.svg) — проверки и создание заявки.
- [Состояния протокола](protocol.svg) — подготовка, отзыв и публикация.
- [Авторизация](authentication.svg) — проверка JWT, активности и прав.

Схемы сохранены в одном векторном формате SVG, без дублирующих PNG и генераторов.
Правила предметной области описаны в [требованиях](../coursework/REQUIREMENTS.md),
таблицы — в [словаре данных](../database/DATA_DICTIONARY.md).
