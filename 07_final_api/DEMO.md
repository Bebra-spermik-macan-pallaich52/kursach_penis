# Демонстрация итогового API

1. Откройте терминал в этой папке. Выполните установку из README на Python 3.12. Базы создаёт scripts/setup_database.sql, таблицы — app.migrate. Если база уже заполнена, повторный --demo сохраняет её.
2. Запустите Uvicorn и откройте /api/v1/docs. Без входа выполните GET /olympiads и фильтр year. Откройте опубликованный протокол. Черновик возвращает 404.
3. Войдите администратором admin. Создайте карточку олимпиады с ответственным teacher1. Даты — сегодняшние: студент сможет записаться, а преподаватель подготовить протокол в день демонстрации.
4. Войдите student1. Запишитесь на созданную олимпиаду, затем ещё на одну доступную. Покажите /users/me/participations и редактирование своего профиля. До публикации баллы скрыты.
5. Войдите teacher1. Покажите запрет изменения чужого мероприятия, создание студента со всеми учебными полями, список своих заявок и ввод баллов 95.5 с результатом winner.
6. Создайте положение через /olympiads/{id}/templates, прикрепите несколько грамот и замените одну из них. Задания текущего года гостю недоступны, прошлых лет — доступны.
7. Подготовьте протокол, отзовите его в draft и подготовьте снова. Публикация преподавателем даёт 403. Переключитесь на admin и опубликуйте; гостю и студенту станут видны результаты. Отзыв опубликованного протокола запрещён.
8. Скачайте протокол в DOCX и XLSX, сравните ФИО, 95.5 и «Победитель». Администратором скачайте годовой отчёт и найдите строку той же олимпиады. Учтите: это отчёт по участиям, один студент может быть в нескольких строках.
9. Откройте /api/v2/docs, сравните список с v1: items, total, page, pageSize; проверьте поиск и пагинацию. Права в обеих версиях одинаковы.
10. Покажите отдельный запуск 88 тестов по README, план, матрицу, тест-кейсы и измеренное покрытие маршрутов/сервисов. Полная история TDD, нагрузка и Windows-проверки не заявляются.

Для воспроизводимой демонстрации полного HTTP-сценария при запущенном на порту 8000 сервере выполните python -m scripts.smoke. Он добавляет учебные данные и сохраняет DOCX/XLSX в reports/smoke. Это реальный сценарий через requests, а не генератор презентации.

Документы для сдачи находятся в docs, пояснительная записка — отдельно в docs/coursework, тестовая документация — в docs/testing. Личные реквизиты заполняются перед сдачей.
