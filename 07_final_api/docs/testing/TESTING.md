Все прежние токены пользователя после этого отклоняются. Просроченный токен обновить нельзя; требуется повторный вход.

## Тестовая база и фикстуры

Имя базы обязано оканчиваться на _test. Перед каждым тестом очищаются только четыре предметные таблицы этой отдельной базы, после теста очистка повторяется. Рабочая БД не очищается. Маршруты используют настоящие соединения psycopg; подмена get_db и эмуляция SQL-запросов не применяются.

| Фикстура | Назначение |
|---|---|
| test_database | Применяет SQL-миграции в отдельной тестовой базе |
| db | Очищает таблицы тестовой базы и предоставляет соединение с autocommit |
| client | TestClient и временное хранилище файлов |
| password_hash | Учебный PBKDF2-хеш для подготовки аккаунтов |
| accounts | Администратор, два преподавателя, два студента |
| headers | Bearer-токены учебных аккаунтов |
| olympiad | Олимпиада с ответственным преподавателем и сегодняшними датами |

План и матрица — [TEST_PLAN.md](TEST_PLAN.md), сценарии — [TEST_CASES.md](TEST_CASES.md). Запуск в Windows указан в README проекта. Полные локальные результаты сохраняются в reports и htmlcov.
